## Summary

`herding-cats` can now consume any [Model Context Protocol](https://modelcontextprotocol.io) server as a tool source, and users can override the (often thin) descriptions that MCP servers advertise via a YAML file.

## What's in this PR

- **`src/herding_cats/mcp.py`** — single new module (~820 lines). Exports `McpServerSpec`, `connect_mcp_servers`, `discover_tools`, `build_input_schema_from_json_schema`, `load_tool_overrides`, `apply_tool_overrides`, `crew_with_mcp`. MCP `tools` are wrapped as `ToolSpec`s; the fetcher calls them through `Executor.arun()` exactly like a local Python tool.
- **`src/herding_cats/crew/runner.py`** — `Crew` dataclass gains one field: `mcp_servers: list[Any]`.
- **`src/herding_cats/__init__.py`** — re-exports the public MCP surface.
- **`pyproject.toml`** — new `[mcp]` extra pins `mcp>=1.0,<2.0` (v1.x maintenance line; v2 changes the public API). `[test]` extra pulls `mcp` so the slow integration suite runs out of the box.
- **`tests/test_mcp_overrides.py`** — ~26 fast tests covering YAML loading, schema resolution, and the warn-on-load contract.
- **`tests/test_mcp_adapter.py`** — ~33 fast tests using fake `ClientSession`s. No subprocess, no network.
- **`tests/test_mcp_integration.py`** — ~7 slow tests spawning an in-process `FastMCP` echo server over stdio.
- **`examples/mcp_fetch_demo.py`** + **`examples/mcp_tool_overrides.yaml`** — end-to-end demo with `mcp-server-fetch`.
- **`docker-compose.yml`** — new `mcp-fetch` service under the `mcp` profile, running `mcp-server-fetch` via `supergateway` over SSE on port `8811`.
- **`README.md`** — new "MCP tools (consume any MCP server)" section.

## Design decisions

1. **Transports:** stdio + HTTP+SSE. No Streamable HTTP this round.
2. **Overrides:** YAML file only. No inline dict, no dynamic callback.
3. **Code path:** single `src/herding_cats/mcp.py`. Not a subpackage.
4. **Unknown override behavior:** warn at load via the `herding_cats.mcp` logger (level WARNING), never raise. Catches typos (e.g. `get_wether`) without breaking the legitimate multi-server use case.
